# Kingdom — muestra visual 3D

Abrir `Assets/Game/Scenes/KingdomPremium.unity` con Unity 6000.3.23f1 y pulsar **Play** para activar el pipeline propio y los controles. El ejecutable de revisión está en `Builds/KingdomPremium/KingdomPremium.exe`.

- Seleccionar Recolector, Guerrero o Héroe desde los botones o pulsando la figura.
- Cambiar entre Cerca, Media y RTS; las teclas 1, 2 y 3 eligen cámara.
- En Cerca, arrastrar para inspeccionar la figura y usar la rueda para acercarse.
- H oculta o muestra los controles.

Los tres personajes tienen poses estáticas y tres LOD. Esta muestra no incluye rig, animaciones ni integración de combate. Las imágenes de presentación se capturan de sus mallas, materiales y cámaras reales de Unity.

La galería `Artifacts/ArtReview/kingdom-premium/index.html` conserva la comparación con la entrega anterior y las láminas originales del usuario. El plan, las procedencias y la evidencia están en `docs/art/art-overhaul-plan.md` y `docs/art/kingdom-premium-production.md`. El nombre de esta carpeta identifica la dirección buscada; no certifica que los modelos sean idénticos a las referencias.
